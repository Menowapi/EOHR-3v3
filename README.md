# EOHR 3v3

Game updates for EOHR 3v3 (Super Marvel vs. Capcom: Eternity of Heroes, Ikemen GO).

Players: start the game with **EOHR 3v3 Launcher.bat** in the game folder. It installs new updates from this repo, then starts the game.

updates.json lists the updates (newest last); each one is a release zip with only the files that changed.
